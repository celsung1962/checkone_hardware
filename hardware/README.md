# hardware

The KiCad project of the CheckOne board (`CheckOne/`, KiCad 10) and the scripts that build it, as in GapOne V2.

| Script | Python | What it does |
|---|---|---|
| `build_symbol_lib.py` | any (sexpdata) | `CheckOne/CheckOne.kicad_sym`: project symbols from the KiCad 10 library or the pin table, fields, pins checked against `docs/datasheets/<part>_pins.csv`; log `symbol_build_log.md` |
| `check_all_symbols.py` | any | every project symbol against its pin table (skill `check_symbol_pins.py`) |
| `gen_checkone.py` | any | the schematic: root + 6 A4 sheets (`schgen.py`); never hand-edit the `.kicad_sch` |
| `sync_board.py` | KiCad | "Update PCB from Schematic": reloads every footprint from its library at the same place, sets values, fields, paths, nets; the rev 1.1 moves only once (board still at rev 1.0) |
| `schgen.py` | any | the schematic writer (GapOne copy, rev 1.1) |

After a schematic change:

```
python hardware/build_symbol_lib.py
python hardware/check_all_symbols.py
python hardware/gen_checkone.py
kicad-cli sch erc hardware/CheckOne/CheckOne.kicad_sch
kicad-cli sch export netlist --format kicadsexpr -o hardware/CheckOne/CheckOne.net hardware/CheckOne/CheckOne.kicad_sch
"C:\Program Files\KiCad\10.0\bin\python.exe" hardware/sync_board.py
python .claude/skills/kicad-schematic/scripts/check_drawing.py hardware/CheckOne/CheckOne.kicad_sch
python .claude/skills/kicad-schematic/scripts/fix_passive_text.py hardware/CheckOne
python tools/hw_checks/hw_checks.py
```
