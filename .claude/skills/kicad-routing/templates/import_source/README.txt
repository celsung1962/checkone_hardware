Golden import source — for loading the standard through the KiCad UI (no scripts)

This folder is a minimal KiCad 9 project that carries the golden settings and nothing else:
  Golden_Import_Source.kicad_pro   rules, DRC/ERC severities, defaults, netclasses + name patterns,
                                   predefined sizes, tuning (chamfer), BOM preset  (generated by apply_settings.js)
  Golden_Import_Source.kicad_pcb   4-layer stackup (F.Cu signal / In1.Cu power / In2.Cu power / B.Cu signal),
                                   tenting front+back, pad-to-mask 0, solder mask min width 0.1; no copper items

Procedure (same as the devboard settings package it was modelled on):
  1. Open YOUR project in the PCB editor.
  2. File -> Board Setup -> "Import Settings from Another Board..." -> pick Golden_Import_Source.kicad_pcb.
  3. Tick the categories you want. Netclasses and Constraints are separate categories: tick both.
     Tick "Layers" only if your board is also 4-layer; the stackup comes with it.
  4. Do NOT import severities from any project other than this one (see references/07, second pass).

Prefer scripts/apply_settings.js when the project is closed: it is exact, diffable and keeps your own
netclasses and DRC exclusions. Regenerate this folder after changing golden_settings.json:
  node scripts/apply_settings.js templates/import_source/Golden_Import_Source.kicad_pro
